# Movies API

Учебный REST API на FastAPI для управления фильмами.

Данные хранятся локально в файле `movies.json` в формате JSON. Валидация входных данных выполняется с помощью Pydantic.

## Установка и запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Убедитесь, что файл `movies.json` находится рядом с `main.py`. Если база данных ещё не создана, создайте файл со следующим содержимым:

   ```json
   []
   ```

3. Запустите сервер:

   ```bash
   uvicorn main:app --reload
   ```

4. Откройте Swagger UI:

   http://127.0.0.1:8000/docs

## Запуск в Docker

В контейнере сервер использует порт `8000`.

1. Соберите Docker-образ:

   ```bash
   docker build -t move-service .
   ```

2. Запустите контейнер:

   ```bash
   docker run -d -p 8000:8000 --name movies-app move-service
   ```

Документация API будет доступна по адресу:

http://localhost:8000/docs

## Эндпоинты

| Метод | Путь | Параметр | Описание |
|---|---|---|---|
| POST | `/` | JSON в теле запроса | Добавить новый фильм. Возвращает созданную запись с идентификатором. |
| GET | `/` | — | Получить список всех фильмов. |
| GET | `/{movie_id}` | `movie_id` в пути | Получить фильм по идентификатору. |
| DELETE | `/{movie_id}` | `movie_id` в пути | Удалить фильм по идентификатору. |

## Структура данных

Каждая запись о фильме содержит следующие поля:

| Поле | Тип | Описание |
|---|---|---|
| `id` | `int` | Уникальный идентификатор фильма. |
| `name` | `str` | Название фильма. |
| `plot` | `str` | Сюжет фильма. |
| `genres` | `List[str]` | Список жанров фильма. |
| `casts` | `List[str]` | Список актёров. |

Пример JSON для добавления фильма:

```json
{
  "name": "Interstellar",
  "plot": "A team of explorers travels beyond this galaxy.",
  "genres": ["Sci-Fi", "Drama"],
  "casts": ["Matthew McConaughey", "Anne Hathaway"]
}
```

Идентификатор `id` создаётся автоматически при добавлении фильма.

## Валидация (Pydantic)

- `name` и `plot` — обязательные непустые строки.
- `genres` — обязательный непустой список строк.
- `casts` — обязательный непустой список строк.

При передаче некорректных данных возвращается HTTP 422 Validation Error.

Если фильм с указанным идентификатором не найден, возвращается HTTP 404 с сообщением `Movie with given id not found`.

## HTTP-статусы

| Код | Описание |
|---|---|
| `200` | Успешное получение данных. |
| `201` | Фильм успешно добавлен. |
| `204` | Фильм успешно удалён. |
| `404` | Фильм с указанным идентификатором не найден. |
| `422` | Ошибка валидации входных данных. |
